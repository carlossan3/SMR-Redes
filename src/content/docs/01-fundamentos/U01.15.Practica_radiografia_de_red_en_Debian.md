# U01.15 — Práctica: radiografía de red en Debian

> 🧭 **Objetivo:** identificar en un equipo real el **hostname**, las **interfaces**, las **direcciones MAC** y las **direcciones IP**, y registrar evidencias sin modificar ningún parámetro.

---

## 🎯 Qué vas a demostrar

Al terminar esta práctica deberías ser capaz de:

- obtener el hostname del equipo;
- enumerar las interfaces de red;
- localizar la MAC de al menos una interfaz;
- localizar la IPv4 de al menos una interfaz;
- distinguir esos datos sin confundirlos;
- explicar qué evidencia has utilizado.

> 📌 Esta práctica es de **observación**. No debes modificar la configuración de red.

---

## 🛡️ Regla de seguridad

Durante toda la práctica utilizarás únicamente comandos de consulta:

```bash
hostname
ip link
ip address
```

No utilices comandos para:

- borrar direcciones;
- bajar interfaces;
- cambiar la MAC;
- cambiar el hostname;
- modificar rutas;
- reiniciar servicios de red.

Si dudas, pregunta antes de ejecutar algo distinto.

---

## 1. Identifica el equipo

Abre una terminal y ejecuta:

```bash
hostname
```

Anota el resultado.

| Dato | Valor observado |
|---|---|
| Hostname | |

### Pregunta

¿El valor obtenido es una dirección IP?

<details>
<summary>🔄 Solución</summary>

No. Es el **hostname**, es decir, el nombre asignado al equipo.

</details>

---

## 2. Localiza las interfaces

Ejecuta:

```bash
ip link
```

Busca los nombres que aparecen al comienzo de cada bloque.

Podrías encontrar nombres como:

```text
lo
enp0s3
enp3s0
wlp2s0
```

Los nombres reales pueden ser diferentes.

### Completa

| Interfaz encontrada | ¿Qué tipo crees que es? | Evidencia o pista |
|---|---|---|
| | | |
| | | |
| | | |

> 💡 `lo` es una interfaz especial de **loopback**. No es un cable físico.

---

## 3. Localiza una dirección MAC

En la salida de:

```bash
ip link
```

busca una línea similar a:

```text
link/ether 52:54:00:12:34:56
```

Registra una interfaz y su MAC.

| Interfaz | Dirección MAC |
|---|---|
| | |

### Comprueba el formato

Una MAC Ethernet suele verse como:

```text
XX:XX:XX:XX:XX:XX
```

donde cada `XX` es un par hexadecimal.

---

## 4. Localiza una dirección IP

Ejecuta:

```bash
ip address
```

Busca dentro de una interfaz una línea que empiece por:

```text
inet
```

Ejemplo:

```text
inet 192.168.1.25/24
```

Registra lo que encuentres.

| Interfaz | Dirección IPv4 observada | Prefijo mostrado |
|---|---|---|
| | | |

> 📌 No tienes que calcular todavía qué significa el prefijo. Solo reconocerlo y separarlo de la dirección.

---

## 6. Fallo conceptual intencionado — El informe de CONRAD

CONRAD ha entregado esta ficha:

```text
Hostname: 192.168.1.34
Interfaz: A4:5E:60:12:34:56
MAC: enp3s0
IP: pc-aula-09
```

Hay **cuatro etiquetas mal colocadas**.

Corrige la ficha suponiendo que los cuatro valores son reales y solo se han asociado a la categoría equivocada.

<details>
<summary>🔄 Solución</summary>

La ficha correcta sería:

```text
Hostname: pc-aula-09
Interfaz: enp3s0
MAC: A4:5E:60:12:34:56
IP: 192.168.1.34
```

La clave está en reconocer el **formato** y la **función** de cada identificador.

</details>

---

## 7. Explica la evidencia

Responde brevemente.

### A

¿Cómo sabes cuál es el hostname?

<details>
<summary>🔄 Respuesta orientativa</summary>

Porque lo he obtenido con el comando:

```bash
hostname
```

</details>

### B

¿Cómo sabes qué nombre corresponde a una interfaz?

<details>
<summary>🔄 Respuesta orientativa</summary>

Porque aparece como encabezado de un bloque en la salida de:

```bash
ip link
```

o:

```bash
ip address
```

</details>

### C

¿Qué texto te ayuda a localizar una MAC?

<details>
<summary>🔄 Respuesta orientativa</summary>

En una interfaz Ethernet aparece normalmente tras:

```text
link/ether
```

</details>

### D

¿Qué texto te ayuda a localizar una IPv4?

<details>
<summary>🔄 Respuesta orientativa</summary>

Aparece normalmente tras:

```text
inet
```

dentro de la interfaz correspondiente.

</details>

- [ ] Sé reconocer el formato de una MAC.
- [ ] Sé localizar una IPv4 sin modificarla.

---

## 🧠 Cierre

Completa esta frase con tus palabras:

> **Un mismo equipo puede tener un hostname, varias interfaces y, en cada interfaz, distintos identificadores porque...**

<details>
<summary>🔄 Ejemplo de respuesta</summary>

Porque el **hostname** nombra al equipo, mientras que cada **interfaz** es un punto distinto de conexión y puede tener su propia **MAC** y su propia **dirección IP**.

</details>

---

## ✅ Evidencia mínima de la práctica

Entrega o conserva:

1. la tabla de interfaces;
2. al menos una pareja **interfaz ↔ MAC**;
3. al menos una pareja **interfaz ↔ IPv4**;
4. la ficha de identidad;
5. la corrección del informe de CONRAD.

> **Observar → identificar → registrar → explicar.** Esa es la práctica técnica de hoy.
