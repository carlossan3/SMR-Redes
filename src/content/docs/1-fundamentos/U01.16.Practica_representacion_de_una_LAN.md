# U01.16 — Práctica: representar una LAN

> 🧭 **Objetivo:** transformar unos requisitos escritos en una representación clara y coherente de una LAN.

Puedes utilizar:

- **Cisco Packet Tracer**;
- **diagrams.net**;
- otra herramienta equivalente autorizada.

No necesitas configurar direcciones IP.

---

## 🎯 Situación

Una pequeña gestoría dispone de:

- `PC-ADM-01`
- `PC-ADM-02`
- `PC-ADM-03`
- `PC-DIR-01`
- `PRN-01` — impresora de red
- `SRV-01` — servidor local
- `SW-01` — switch
- `AP-01` — punto de acceso
- `R-01` — router
- `PORT-01`
- `PORT-02`

Condiciones:

- los cuatro PCs, la impresora, el servidor, el AP y el router se conectan por cable al switch;
- los dos portátiles se conectan por Wi-Fi al AP;
- el router conecta la LAN con otra red;
- el switch es el centro de la estrella cableada.

| `SW-01` | | | |
| `AP-01` | | | |
| `R-01` | | | |
| `PORT-01` | | | |

<details>
<summary>🔄 Solución orientativa</summary>

| Elemento | Final / intermedio | Conexión | Función básica |
|---|---|---|---|
| `PC-ADM-01` | Final | Cable | Equipo de usuario |
| `PRN-01` | Final | Cable | Recurso compartido |
| `SRV-01` | Final | Cable | Ofrece servicios |
| `SW-01` | Intermedio | Cable | Interconecta equipos de la LAN |
| `AP-01` | Intermedio | Cable hacia LAN / Wi-Fi hacia clientes | Incorpora dispositivos inalámbricos |
| `R-01` | Intermedio | Cable | Conecta redes diferentes |
| `PORT-01` | Final | Wi-Fi | Equipo de usuario |

</details>

---

## 2. Haz un boceto previo

Antes de abrir la herramienta, dibuja un esquema rápido.

Debe parecerse conceptualmente a:

```text
equipos cableados
       ↓
     SW-01
     /   \
 AP-01   R-01
  ↓       ↓
Wi-Fi   otra red
```

No copies este boceto como resultado final: úsalo para organizar tus ideas.

---

## 3. Construye el diagrama

Tu diagrama debe incluir:

- todos los dispositivos indicados;
- sus nombres exactos;
- enlaces cableados claramente representados;
- enlaces Wi-Fi diferenciados;
- conexión del router con «otra red»;
- distribución legible;
- una pequeña leyenda.

### Leyenda mínima sugerida

```text
────────   enlace cableado
- - - -    enlace Wi-Fi
```

---

## 4. Fallo intencionado — El plano heredado

Otro técnico ha dejado estas decisiones:

1. `PORT-01` aparece unido por cable a `SW-01`.
2. `AP-01` aparece aislado, sin conexión con la LAN.
3. `R-01` aparece conectado únicamente a «otra red», pero no a `SW-01`.
4. Todos los PCs se llaman simplemente `PC`.

### Tu tarea

Para cada error:

- indica qué está mal;
- explica por qué dificulta o falsea la representación;
- corrígelo en tu diagrama.

<details>
<summary>🔄 Solución orientativa</summary>

1. `PORT-01` debe representarse conectado **por Wi-Fi al AP**, según los requisitos.
2. `AP-01` debe estar conectado a la **LAN**, normalmente mediante enlace con `SW-01`.
3. `R-01` debe tener relación con la LAN a través de `SW-01` y además con la otra red.
4. Los PCs deben tener nombres diferenciados (`PC-ADM-01`, `PC-ADM-02`...), para poder identificarlos sin ambigüedad.

</details>

---

## 5. Comprueba tu propio trabajo

Usa esta lista:

- [ ] Están todos los dispositivos.
- [ ] No he inventado dispositivos que no aparecen en el escenario.
- [ ] Cada dispositivo tiene un nombre identificable.
- [ ] El switch ocupa el centro de la estrella cableada.
- [ ] El AP está conectado a la LAN.
- [ ] Los portátiles aparecen asociados al AP.
- [ ] El router conecta la LAN con otra red.
- [ ] Distingo cable y Wi-Fi.
- [ ] Hay una leyenda.
- [ ] El esquema se entiende sin que yo tenga que explicarlo oralmente.

---

## 6. Justificación técnica breve

Responde:

1. ¿Qué topología domina en la parte cableada?
2. ¿Por qué la red es mixta?
3. ¿Qué dispositivo conecta redes diferentes?
4. ¿Qué dispositivo incorpora clientes inalámbricos?
5. ¿Qué cambiarías en el diagrama si el AP estuviera físicamente en otra sala?

<details>
<summary>🔄 Respuestas orientativas</summary>

1. **Estrella**, con `SW-01` como elemento central.
2. Porque combina **enlaces cableados y Wi-Fi**.
3. `R-01`, el **router**.
4. `AP-01`, el **punto de acceso**.
5. En un **mapa físico** reflejaría su nueva ubicación. En un mapa lógico podría mantenerse la misma relación funcional si sigue conectado de la misma forma.

</details>

## ✅ Evidencia de la práctica

Conserva o entrega:

1. el diagrama final;
2. la leyenda;
3. la corrección de los cuatro errores;
4. las cinco respuestas de justificación.

> **Un mapa técnico está terminado cuando otra persona puede interpretarlo sin tener que preguntarte qué significa.**
