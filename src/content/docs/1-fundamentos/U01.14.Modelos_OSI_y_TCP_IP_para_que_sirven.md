# U01.14 — Modelos OSI y TCP/IP: para qué sirven

## 🎯 Qué vas a conseguir

Al terminar este apartado deberías ser capaz de:

- explicar por qué resulta útil dividir una comunicación de red en **capas**;
- reconocer las **7 capas del modelo OSI** y asociarlas con una función general;
- comprender que OSI es principalmente un **modelo de referencia**;
- reconocer las capas principales del modelo **TCP/IP**;
- relacionar de forma sencilla OSI y TCP/IP;
- situar conceptos ya conocidos —cable, MAC, IP, TCP/UDP y aplicaciones— en el lugar que les corresponde;
- utilizar las capas como un **mapa mental** para razonar sobre una comunicación.

> 📌 **CE principal:** RA1.a — comprensión inicial de las reglas y la organización de la comunicación. También refuerza la lectura funcional de los elementos de red de RA1.c.

---

## 📬 Idea clave

> **Los modelos OSI y TCP/IP dividen una comunicación compleja en partes más pequeñas para poder entender qué función realiza cada una.**

No son una colección de palabras para recitar.

Son **mapas**.

Cuando una red parece complicada, separar funciones ayuda a responder preguntas como:

- ¿el problema está en el medio?
- ¿en la comunicación dentro de la LAN?
- ¿en el direccionamiento?
- ¿en el transporte?
- ¿en la aplicación?

---

## 🏭 Por qué dividir un problema en capas

Piensa en una empresa que envía un producto.

No hay una sola persona que haga todo:

1. alguien prepara el pedido;
2. otra persona organiza el transporte;
3. otra decide la ruta;
4. alguien prepara el envío local;
5. finalmente el producto se mueve físicamente.

Separar tareas aporta ventajas:

- cada parte tiene una responsabilidad;
- es más fácil sustituir una tecnología;
- se pueden crear estándares;
- resulta más sencillo localizar problemas;
- permite que distintos fabricantes trabajen con reglas comunes.

En redes ocurre algo parecido.

## 🧱 El modelo OSI

**OSI** significa *Open Systems Interconnection*.

Es un modelo de referencia que organiza la comunicación en **7 capas**.

```text
7  Aplicación
6  Presentación
5  Sesión
4  Transporte
3  Red
2  Enlace de datos
1  Física
```

No todas las capas tendrán ahora la misma importancia para ti.

En este módulo volverás constantemente a las capas inferiores y medias porque ayudan a entender:

- el medio físico;
- Ethernet y MAC;
- IP;
- transporte;
- servicios de aplicación.

---

## 🗂️ Las 7 capas, con una función sencilla

| Capa | Nombre | Pregunta sencilla |
|---:|---|---|
| **7** | Aplicación | ¿Qué servicio de red utiliza la aplicación? |
| **6** | Presentación | ¿Cómo se representa o transforma la información? |
| **5** | Sesión | ¿Cómo se mantiene organizada una sesión de comunicación? |
| **4** | Transporte | ¿Cómo se transportan los datos entre aplicaciones? |
| **3** | Red | ¿Cómo se identifica y alcanza una red o un destino lógico? |
| **2** | Enlace de datos | ¿Cómo se comunica un dispositivo dentro del enlace o LAN local? |
| **1** | Física | ¿Cómo se transmiten físicamente los bits? |

### Relación con cosas que ya conoces

| Concepto | Capa que te ayuda a situarlo |
|---|---|
| Cable de cobre, fibra, radio | 1 · Física |
| Ethernet y direcciones MAC | 2 · Enlace |
| Dirección IP y router | 3 · Red |
| TCP y UDP | 4 · Transporte |
| HTTP, DNS y otros servicios | 7 · Aplicación |

> 📌 Esta tabla es una **orientación inicial**. Más adelante estudiarás algunos de estos protocolos con mucho más detalle.

---

## 🧠 No memorices sin entender

Un error clásico consiste en aprender:

```text
Aplicación - Presentación - Sesión - Transporte - Red - Enlace - Física
```

y no saber qué significa nada.

Es mejor ser capaz de razonar:

> «Si el cable está desconectado, el problema está abajo, en la parte física».

o:

> «Si el equipo está conectado pero no tiene un direccionamiento lógico válido, ya no estoy hablando del cable».

Las capas sirven para **ordenar el pensamiento técnico**.

## 🌍 El modelo TCP/IP

La familia **TCP/IP** es la base de la comunicación en Internet y en la mayoría de las redes actuales.

Se suele representar con **4 capas**:

```text
APLICACIÓN
TRANSPORTE
INTERNET
ACCESO A RED
```

### Relación sencilla con OSI

| Modelo OSI | Modelo TCP/IP |
|---|---|
| 7 Aplicación + 6 Presentación + 5 Sesión | **Aplicación** |
| 4 Transporte | **Transporte** |
| 3 Red | **Internet** |
| 2 Enlace + 1 Física | **Acceso a red** |

> 💡 OSI separa más las funciones y resulta muy útil para **aprender y razonar**. TCP/IP agrupa algunas de ellas y describe mejor la pila de protocolos utilizada en redes reales.

---

## ⚖️ OSI y TCP/IP no son rivales

No tienes que elegir uno y tirar el otro.

Puedes utilizarlos para objetivos diferentes.

### OSI

Te ayuda a:

- estudiar;
- ordenar conceptos;
- explicar una comunicación;
- razonar por capas;
- localizar de forma inicial dónde puede estar un problema.

### TCP/IP

Te ayuda a:

- comprender la organización práctica de los protocolos de Internet;
- relacionar aplicación, transporte, direccionamiento y acceso a red.

> **Pensamiento profesional:** OSI es un mapa conceptual muy detallado; TCP/IP es una organización más cercana a la pila real que utilizamos.

## 📦 ¿Qué ocurre al enviar información?

Sin entrar todavía en cabeceras ni formatos, piensa en este recorrido:

```text
APLICACIÓN
   ↓
TRANSPORTE
   ↓
RED / INTERNET
   ↓
ENLACE
   ↓
FÍSICA
```

Al enviar información, cada nivel cumple su parte antes de que los datos lleguen al medio.

En el receptor ocurre el proceso inverso.

Más adelante estudiarás este proceso con el nombre de **encapsulación y desencapsulación**.

Hoy basta con entender que:

> **La comunicación no es una única operación: es una cadena de funciones coordinadas.**

## 🏫 Ejemplo guiado — Abrir una página del servidor del centro

Imagina que desde un PC abres una página alojada en un servidor.

De forma muy simplificada:

1. una **aplicación** solicita la página;
2. la capa de **transporte** ayuda a llevar la conversación entre aplicaciones;
3. la capa de **red** utiliza direcciones lógicas para alcanzar el destino;
4. la capa de **enlace** permite el movimiento dentro del enlace local;
5. la capa **física** convierte finalmente la información en señales por el medio.

No necesitas conocer aún todos los detalles.

Sí debes ser capaz de ver que cada parte responde a **una pregunta distinta**.

> **CONRAD:** —Aplicación, Presentación, Sesión, Transporte...
>
> —¿Qué estás haciendo?
>
> **CONRAD:** —Memorizando. Si lo recito en menos de cinco segundos, ya sé redes.

> **CONRAD:** —¿Eso cae en Presentación?

Conclusión:

> **Saber el nombre de una capa importa menos que comprender qué tipo de función representa.**

## 🧠 Actividad integrada — Ordena el problema

Relaciona cada situación con la capa OSI que mejor ayuda a pensar en ella.

1. El cable de red está desconectado.
2. Queremos identificar un dispositivo dentro de la LAN mediante su MAC.
3. Un router debe trabajar con una dirección IP.
4. Una aplicación web necesita intercambiar datos con otra aplicación.
5. Queremos pensar en cómo se transportan datos entre aplicaciones.

<details>
<summary>🔄 Solución</summary>

1. **Capa 1 — Física**.
2. **Capa 2 — Enlace de datos**.
3. **Capa 3 — Red**.
4. **Capa 7 — Aplicación** como punto de partida del servicio.
5. **Capa 4 — Transporte**.

</details>

---

## ✅ Resumen en 3 frases

1. El modelo **OSI** divide la comunicación en 7 capas para separar funciones y facilitar la comprensión.
2. El modelo **TCP/IP** agrupa esas funciones en 4 capas y está directamente relacionado con la pila utilizada en las redes actuales.
3. Las capas son un **mapa mental**: sirven para comprender qué hace cada parte de una comunicación, no solo para memorizar nombres.
