# U01.17 — Caso integrador: comprender y representar una LAN

> 🗺️ **Ruta de la UT:** ✅ Fundamentos → ✅ Componentes → ✅ Clasificaciones → ✅ Arquitecturas → ✅ Topologías → ✅ Dispositivos → ✅ Medios → ✅ Packet Tracer → ✅ Protocolos → ✅ OSI/TCP-IP → ✅ Identificadores → ✅ Mapas → **🧠 AQUÍ ESTÁS — Caso integrador**

Esta sesión no introduce una colección nueva de conceptos.

Su objetivo es que demuestres que puedes **combinar lo aprendido** para comprender una LAN completa y representarla con criterio.

---

## 🎯 Qué vas a demostrar

A partir de un escenario profesional deberás:

- identificar los elementos de una red;
- clasificar la red desde varios puntos de vista;
- reconocer dispositivos finales e intermedios;
- diferenciar cliente-servidor y P2P;
- reconocer la topología;
- seleccionar medios;
- relacionar switch, router y AP con su función;
- explicar por qué hacen falta protocolos;
- situar conceptos básicos en OSI/TCP-IP;
- distinguir interfaz, MAC, IP y hostname;
- construir una representación coherente;
- detectar y corregir errores visibles;
- justificar tus decisiones.

# 🏢 El caso — Aula Nova Formación

Una academia ocupa una sola planta de un edificio.

Dispone de:

### Aula de informática

- 8 PCs de alumnado:
  - `PC-A01` a `PC-A08`
- 1 PC del docente:
  - `PC-PROF`
- 1 impresora:
  - `PRN-AULA`

### Administración

- 2 PCs:
  - `PC-ADM01`
  - `PC-ADM02`

### Servicios

- 1 servidor local:
  - `SRV-CENTRO`

### Interconexión

- 1 switch:
  - `SW-01`
- 1 router:
  - `R-01`
- 1 punto de acceso:
  - `AP-01`

### Dispositivos móviles

- 3 portátiles:
  - `PORT-01`
  - `PORT-02`
  - `PORT-03`

### Requisitos

- todos los equipos fijos se conectan por Ethernet a `SW-01`;
- `AP-01` se conecta a `SW-01`;
- los tres portátiles acceden mediante Wi-Fi a `AP-01`;
- `R-01` conecta la LAN con la red del operador;
- `SRV-CENTRO` ofrece archivos al resto de equipos;
- algunos PCs también pueden compartir puntualmente una carpeta entre ellos;
- la red debe poder documentarse mediante un diagrama comprensible.

---

# 1. Comprende la red

## A. ¿Es una LAN?

Explica por qué.

<details>
<summary>🔄 Solución orientativa</summary>

Sí. Los dispositivos se encuentran dentro de un ámbito local reducido —una planta de una academia— y forman una red local administrada como una unidad.

</details>

## B. ¿Es cableada, inalámbrica o mixta?

<details>
<summary>🔄 Solución</summary>

Es **mixta**: los equipos fijos utilizan Ethernet y los portátiles utilizan Wi-Fi.

</details>

## C. Identifica dispositivos finales e intermedios

Completa:

| Dispositivo | Final / intermedio | Motivo |
|---|---|---|
| `PC-A01` | | |
| `PRN-AULA` | | |
| `SRV-CENTRO` | | |
| `SW-01` | | |
| `R-01` | | |
| `AP-01` | | |
| `PORT-01` | | |

<details>
<summary>🔄 Solución orientativa</summary>

- PCs, impresora, servidor y portátiles → **dispositivos finales**.
- switch, router y AP → **dispositivos intermedios**.

</details>

# 2. Arquitectura de la comunicación

`SRV-CENTRO` ofrece archivos al resto de equipos.

### Pregunta

¿Qué arquitectura representa principalmente?

<details>
<summary>🔄 Solución</summary>

**Cliente-servidor**. El servidor proporciona el servicio y los demás equipos actúan como clientes cuando lo solicitan.

</details>

Dos PCs comparten puntualmente una carpeta directamente entre ellos.

### Pregunta

¿Qué modelo aparece en ese intercambio?

<details>
<summary>🔄 Solución</summary>

Puede considerarse una situación **P2P**, porque los equipos intercambian recursos directamente y uno puede actuar como proveedor para el otro.

</details>

### Conclusión

La misma red puede combinar diferentes formas de organización según el servicio utilizado.

---

# 3. Topología

La mayoría de los dispositivos cableados se conectan a `SW-01`.

### Pregunta

¿Qué topología física domina?

<details>
<summary>🔄 Solución</summary>

Una **estrella**, porque los equipos cableados tienen como punto central el switch.

</details>

### Predicción

¿Qué ocurre si se desconecta el cable de `PC-A04`?

<details>
<summary>🔄 Solución</summary>

En principio se pierde la conexión de ese equipo, pero los demás enlaces de la estrella pueden seguir funcionando.

</details>

¿Qué ocurre si `SW-01` queda fuera de servicio?

<details>
<summary>🔄 Solución</summary>

La parte de la red que depende del switch pierde su punto central de interconexión.

</details>

# 6. Comunicación y protocolos

Un PC está perfectamente cableado al switch.

### Pregunta

¿Eso garantiza por sí solo que pueda intercambiar correctamente información con cualquier servicio?

<details>
<summary>🔄 Solución</summary>

No. La conexión física es necesaria, pero los dispositivos necesitan además **reglas y protocolos compatibles**, así como una configuración adecuada para la comunicación que se pretende realizar.

</details>

### Explica con tus palabras

¿Por qué los estándares son importantes en esta academia si los PCs, el switch, el AP y el servidor pueden ser de fabricantes diferentes?

<details>
<summary>🔄 Respuesta orientativa</summary>

Porque los estándares permiten que equipos de distintos fabricantes utilicen reglas compatibles e interoperables.

</details>

# 8. Identificadores

Uno de los equipos muestra:

```text
hostname: PC-ADM01
interfaz: enp0s3
MAC:      52:54:00:2A:11:7C
IPv4:     192.168.10.21
```

### Explica cada dato

<details>
<summary>🔄 Solución orientativa</summary>

- `PC-ADM01` → **hostname**, nombre del equipo.
- `enp0s3` → nombre de la **interfaz**.
- `52:54:00:2A:11:7C` → dirección **MAC** de la interfaz.
- `192.168.10.21` → dirección **IPv4** asociada a la interfaz en esa red.

</details>

> 📌 No tienes que calcular la red ni la máscara en este caso.

# 10. Fallos intencionados — El diseño de CONRAD

Antes de dar el proyecto por terminado, compara tu red con este informe defectuoso:

```text
1. SRV-CENTRO está colocado como dispositivo intermedio.
2. AP-01 no tiene conexión con SW-01.
3. PORT-01, PORT-02 y PORT-03 aparecen unidos por cable al switch.
4. R-01 está conectado a la red del operador, pero no a la LAN.
5. PC-A01, PC-A02 y PC-A03 se llaman todos "PC".
6. El plano dice que toda la red es "inalámbrica".
```

### Tarea

Para cada punto:

1. identifica el error;
2. corrígelo;
3. justifica la corrección usando vocabulario de U01.

<details>
<summary>🔄 Solución orientativa</summary>

1. `SRV-CENTRO` es un **dispositivo final** que ofrece servicios.
2. `AP-01` debe integrarse en la LAN mediante conexión con el switch.
3. Los portátiles deben representarse como clientes **Wi-Fi** del AP.
4. El router debe relacionarse con la LAN y con la red externa.
5. Los equipos necesitan **nombres diferenciados** para documentarlos sin ambigüedad.
6. La red es **mixta**, porque combina Ethernet y Wi-Fi.

</details>
